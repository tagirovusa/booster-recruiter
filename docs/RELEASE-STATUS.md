# 0.3.2: узкие окна, точные статусы, Patchright в коде

Список изменений: [что нового в 0.3.2](releases/0.3.2-changes.md). Предыдущие версии: [0.3.1](releases/0.3.1-changes.md), [0.3.0](releases/0.3.0-changes.md).

## Проверено на Mac (Apple Silicon), 08.11.2026
- **Исходный код:** 439 Python-тестов, все наборы интерфейса (`npm run test:ui`), проверка репозитория на приватные данные и сканирование истории на секреты.
- **Сборка:** ad hoc подпись (`CSC_IDENTITY_AUTO_DISCOVERY=false`, как в CI), самопроверка встроенного бэкенда (16 MCP-инструментов), `codesign --verify --deep --strict` проходит.
- **Установка:** 0.3.2 из DMG поверх 0.3.1; все 23 набора интерфейса прогнаны на установленном приложении.
- **Patchright:** пакетов Playwright нет в `uv.lock`, `package-lock.json`, `node_modules` и собранном приложении.
- **Реальные данные** (12 кампаний, два аккаунта):
  - поиск в LinkedIn, продолжение поиска без дублей, распознавание рамки Hiring;
  - «Посмотреть перед запуском» и **живая отправка**: приглашение одному получателю подтверждено LinkedIn как ожидающее принятия; история, статус «Ждём принятия» и защита от повторного контакта работают;
  - «Проверить вход», «Обновить Recruiter», «Ответить в LinkedIn»;
  - Excel-экспорт, переименование, архив, возврат, удаление, резервная копия;
  - все экраны проверены при минимальном размере окна 1000×700;
  - `errors.log` не появился.

## Не проверялось в этой версии
- Восстановление копии на рабочих данных: требует повторного входа во все аккаунты. Покрыто автоматическими тестами.
- Windows: [инструкция проверки](WINDOWS-ACCEPTANCE.md).
- Подпись: ad hoc, без Developer ID и notarization; macOS может предупредить о неизвестном разработчике.
