# 0.2.5 — кандидат для приёмки, не клиентский релиз

Версия исправляет распознавание Connect в новых карточках LinkedIn, исключает общих знакомых из результатов поиска, принимает одну точную ссылку на профиль, включая кириллицу, и сохраняет непроверенные по рамке профили в нейтральной группе.

В очереди пауза освобождает ожидающую кампанию сразу. Если действие LinkedIn уже началось, приложение дожидается результата и сохраняет его; неизвестный исход не запускается повторно. Уведомления об успешных действиях относятся только к экрану, на котором они возникли. Черновики настроек сохраняются при переходах между разделами.

Для компактных карточек Recruiter без ссылки на контакты адресат дополнительно проверяется через его нативный идентификатор и обратную ссылку на утверждённый публичный профиль. Эта проверка выполнена чтением на согласованном тестовом профиле; LinkedIn показал платный канал стоимостью 1 кредит. Фактическая отправка в этом кандидате ещё не подтверждена.

## Подтверждённые проверки исходного кода

- 217 тестов логики: данные, ограничения, разделение отправителей, паузы, неизвестный исход и запрет повторов.
- 99 автономных сценариев Chromium: 11 подтверждений обычной отправки, 53 сценария контактов, 35 Recruiter. Внешние запросы блокируются или заменяются локальными документами.
- 23 группы проверок интерфейса с локальным API: настройки, черновики, ошибки, навигация, предпросмотр, история, экспорт и границы уведомлений.
- Чтение настоящих страниц: обычный тестовый аккаунт и тестовый аккаунт Recruiter, варианты Connect, поиск на двух страницах, точное соответствие адресата Recruiter. Это не доказательство всех вариантов LinkedIn.

## Продолжающаяся приёмка

Сборки, установка и живые проверки этой версии фиксируются отдельно после завершения. Сбор двух кампаний по 20 профилей, согласованный платный InMail и актуальная проверка ответов ещё выполняются. Старые реальные тесты приглашения, принятия, обычного сообщения и бесплатного Recruiter InMail описаны в `RELEASE-STATUS-0.2.1.md`; их нельзя считать новыми тестами 0.2.5.

Windows-сборка и установка требуют выполнения `BUILD-WINDOWS.cmd` и процедуры `WINDOWS-ACCEPTANCE.md` на Windows x64. Наличие исходного ZIP не подтверждает наличие рабочего установщика. Пользователь сообщил, что отдельного аккаунта Premium Career/Business нет: обычный Premium InMail проверен автономно, но не в реальном аккаунте. Recruiter не заменяет эту проверку.

Распространение — напрямую, без магазина. Mac использует ad hoc подпись без Developer ID/notarization; Windows пока без издательской подписи. Это ограничения доверия при установке. Не отключайте системную защиту.

Production-ready: false. Передачи клиенту и публикации нет. Действующие ограничения LinkedIn и изменение страниц могут останавливать действия; приложение показывает неопределённый исход, когда подтверждения недостаточно.
