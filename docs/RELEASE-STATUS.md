# 0.2.2 — скрытый браузер для кампаний

Версия установлена на Mac пользователя. Все три аккаунта, шесть кампаний и количество сохранённых профилей в каждой кампании перенесены без изменений. Установленная версия завершила проверку контактов в тестовой кампании без видимых окон браузера и без отправок.

Обновление разделяет ручную работу и автоматизацию. Поиск, чтение профилей, проверки контактов, обычные сообщения и InMail запускаются в нативном скрытом режиме Chromium. Видимое окно используется для ручного входа, подключения Recruiter, открытия профиля пользователем и обязательных проверок LinkedIn.

Переключение режима сначала завершает предыдущий процесс браузера, затем открывает тот же сохранённый профиль. Одновременный доступ двух процессов к одному профилю запрещён. Изменения не дают новых разрешений на отправку.

## Проверки

- 124 теста логики, включая порядок завершения/запуска процессов и выбор режима для ручного входа и фоновой проверки.
- 45 проверок DOM обычных сообщений, контактов и Recruiter.
- Настоящий Chromium в скрытом режиме: отображение страницы и сохранение тестовой сессии между запусками проверены без LinkedIn.
- На Mac, тестовый аккаунт Recruiter: собственный профиль и Recruiter проверены в скрытом режиме; CoreGraphics подтвердил отсутствие видимых окон.
- На Mac, аккаунт Daniil: скрытое чтение собственного профиля → видимый ручной вход → скрытый поиск. Личность сохранилась; поиск вернул профили. CoreGraphics подтвердил отсутствие видимых окон у процессов рабочего браузера.

Проверки 0.2.1, включая реальное приглашение, принятие, обычное сообщение и бесплатный Recruiter InMail, описаны в `RELEASE-STATUS-0.2.1.md`. Для проверки этого обновления новые приглашения и сообщения не отправлялись.

## До передачи клиенту

Новая версия Windows ещё требует проверки на Windows. Фактическое платное списание кредита и настоящий входящий ответ на Recruiter InMail остаются непроверенными. macOS использует ad hoc подпись без Developer ID/notarization. Передачи клиенту нет; production-ready: false до приёмки.
