# 0.3.0: простой интерфейс, понятные ошибки, чистый код

**Production-ready: false.** Сборка-кандидат для живой приёмки. Клиенту ещё не передавалась.

Полный список изменений для рекрутера: [что нового в 0.3.0](releases/0.3.0-changes.md).

## Изменения
- Технические и английские ошибки заменены короткими русскими фразами. Исходный текст сохраняется в локальный `errors.log`.
- Пока браузер занят, вход, предпросмотр и открытие профиля сразу отвечают, какая кампания его держит.
- Сбой задачи переводит кампанию на паузу, а не оставляет её «в работе».
- Появилось управление кампаниями: изменить, перенести в архив, вернуть из архива и удалить, если обращений не было.
- Упрощён интерфейс:
  - два способа связи;
  - одно поле поиска;
  - единые названия действий и статусов;
  - кнопка «Ответить в LinkedIn».
- Работа в фоне включена по умолчанию, при закрытии окна с работающими кампаниями приложение спрашивает, что делать.
- Обновлён визуальный стиль: цветовые токены, шрифт не меньше 12 px, контраст AA, красные кнопки для опасных действий.
- Запуск отправки, восстановление копии и удаление требуют токена окна приложения. MCP-агент получает отказ 403.
- Копии из прошлых версий восстанавливаются, нехватка места на диске объясняется понятно.
- Старая система рассылки удалена. Её отправленная история по-прежнему защищает от повторного контакта.
- Код интерфейса разбит на экраны и модули: самый крупный файл около 720 строк вместо ~2840. Бэкенд Recruiter и «починки приглашений» упрощён без изменения поведения.

## Проверки
- **Исходный код:**
  - 436 Python-тестов: 14 тестов удалённого отправителя убраны, добавлены тесты ошибок, управления кампаниями, доступа и копий;
  - 47 проверок оболочки и состояний, 40 сравнений валидации, smoke, 18 групп регрессий, сценарии рабочего пространства и внимания;
  - проверка репозитория на приватные данные.
- **Упакованная Mac-версия:** тот же полный набор интерфейса; самопроверка встроенного бэкенда подтвердила 16 MCP-инструментов.
- **Установка на Mac:** 0.3.0 поставлена обычным способом поверх 0.2.14.
  - Аккаунты, 11 кампаний и история сохранились, `errors.log` после запуска не появился.
  - Прежний сырой JSON в статусе кампании показывается русской фразой.
  - Агентский токен получает отказ на запуск отправки.
  - Новых исходящих действий не создано.
