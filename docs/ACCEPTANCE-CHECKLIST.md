# Booster Recruiter 0.2.15: живая проверка перед релизом

Проверка идёт на реальных аккаунтах LinkedIn и отправляет настоящие сообщения. Получателей выбирает и подтверждает владелец аккаунта.

- **Перед началом:** **Настройки** → **Создать копию сейчас**.
- **Для каждого пункта записывайте:** дату, версию, аккаунт, результат (✅ / ❌) и что показал экран. Если результат ❌, сделайте скриншот и сохраните `errors.log` из папки данных.

## 1. Установка и запуск
- [ ] Установка из DMG. При первом запуске macOS может показать предупреждение о неподписанном приложении.
- [ ] Данные прошлой версии открылись: кампании, кандидаты и история на месте.
- [ ] В статусах кампаний нет английского текста и JSON.

## 2. Аккаунты
- [ ] **Проверить вход** на каждом аккаунте: статус «Готово».
- [ ] Recruiter: **Обновить Recruiter** показывает контракт и баланс.
- [ ] Пока идёт сбор кандидатов, **Проверить вход** на другом аккаунте сразу говорит «Браузер занят кампанией…», а не висит.

## 3. Кампания и поиск
- [ ] Новая кампания с одной должностью: создаётся сразу, часовой пояс совпадает с вашим.
- [ ] **Найти кандидатов** на 15–20 профилей: список растёт, **Пауза** останавливает сбор.
- [ ] **Изменить** → увеличить число профилей → **Продолжить поиск** находит новых людей.
- [ ] Группы Open to Work, «Обычный текст» и «Без группы» выглядят правдоподобно; группу можно сменить вручную.

## 4. Отправка: «Без InMail»
- [ ] 2–3 получателя → **Посмотреть перед запуском**: тексты с подставленными именами.
- [ ] **Запустить отправку**: в рабочие часы уходит сообщение или приглашение.
- [ ] Принятое приглашение приводит к отправке сообщения (может занять часы).
- [ ] **Пауза** и **Продолжить** работают; повторной отправки нет.

## 5. Отправка: «С InMail» через Recruiter
- [ ] Один получатель без бесплатной связи: превью показывает подпись Recruiter и максимальный расход кредитов.
- [ ] После отправки баланс уменьшился не больше, чем показывало превью.

## 6. Ответы
- [ ] Ответ кандидата появляется в **Требует внимания** → **Новые ответы**.
- [ ] **Ответить в LinkedIn** открывает профиль кандидата в сессии отправителя.
- [ ] После ответа приложение больше не пишет этому человеку.

## 7. Работа в фоне и перезапуск
- [ ] Закрыть окно при работающей кампании: работа продолжается, значок остаётся в строке меню.
- [ ] Выключить работу в фоне и закрыть окно: появляется вопрос «Работать в фоне / Закрыть и остановить / Отмена».
- [ ] Перезапуск компьютера посреди кампании: после запуска кампания на паузе или ждёт расписания, повторов нет.

## 8. Архив, удаление, копии
- [ ] Тестовую кампанию без сообщений можно удалить.
- [ ] Кампанию с сообщениями можно только перенести в архив; после **Вернуть из архива** повторной отправки нет.
- [ ] Восстановление сегодняшней копии: кампании на паузе, история на месте.

## 9. Ошибки
- [ ] Отключить интернет во время сбора: понятное сообщение по-русски, кампания на паузе.
- [ ] Ни на одном шаге не появился английский текст, JSON или путь к файлу.

## Итог
Релиз готов, когда все пункты отмечены ✅, а найденные ❌ исправлены и перепроверены.
