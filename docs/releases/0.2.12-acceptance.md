# 0.2.12 — рабочее пространство рекрутера

**Production-ready: false.** Кандидат для приёмки. Передача клиенту не выполнялась.

## Изменения

- Общий список ответов, запросов входа и действий для проверки. Переход к нужному аккаунту или записи истории; прочитанные ответы можно убрать из списка.
- Простой конструктор поискового запроса с должностями, отраслью, ключевыми и исключаемыми фразами; расширенный запрос остаётся редактируемым.
- В кампании показано следующее запланированное событие и действие при остановке. Настройка компактнее, основные кнопки закреплены.
- Шаблоны кампаний сохраняют поиск, тексты и правила. Созданная из шаблона кампания не наследует получателей, историю или разрешение отправки.
- Необязательные тихие системные уведомления о новых ответах и проблемах. Имена и тексты в уведомления не попадают; исходная история не вызывает поток уведомлений.
- Ежедневные локальные копии бизнес-данных и ручное создание/восстановление. Сессии LinkedIn и пароли исключены. Перед восстановлением сохраняется текущая копия; аккаунты требуют входа, кампании останавливаются, разрешения отправки сбрасываются. Защита от повторного контакта сохраняется. Копии на одном диске не заменяют внешнюю резервную копию.
- Все действия LinkedIn и браузерные тесты используют Patchright. Случайные паузы сохраняются. Функции работают без ИИ.

## Проверки

Исходный код прошёл 365 тестов Python из чистого снимка репозитория, 44 проверки оболочки и новых состояний, 40 сравнений валидации, smoke, 18 групп регрессий и отдельный набор сценариев рабочего пространства. Независимая проверка Electron на 1000×700 и 1380×700 подтвердила фокус восстановления, видимость кнопок, валидацию поиска и клавиатурное управление. Упакованная Mac-версия из проверенного кода прошла те же 44 проверки оболочки, 40 сравнений валидации, smoke, 18 групп регрессий и новый сценарий рабочего пространства: чтение ответа, поиск, создание пустой кампании из шаблона, настройки уведомлений, создание/отмена/восстановление копии. Скриншоты проверены при ширине 1000 и 1380 пикселей, включая фокус и отсутствие перекрытий в настройках.

Самопроверка встроенного runtime прошла 131 DOM-сценарий и проверку встроенного Chromium/OCR; проверены 16 публичных MCP-инструментов и новые операции внимания, шаблонов и копий. Один локальный прогон превысил 120-секундный срок при одновременной упаковке и UI-тестах; после завершения конкурирующих работ тот же прогон успешно завершился за 28,9 с. Срок ожидания не увеличивали.

Финальная Mac-сборка установлена обычным способом: сохранены 3 аккаунта, 11 кампаний, 101 профиль и 16 записей действий. Новый список внимания прочитан из существующей базы, ежедневная копия создана без ошибки. Проверены целостность ZIP и строгая подпись приложения внутри DMG, смонтированного только для чтения; файл приложения соответствует финальному пакету.
