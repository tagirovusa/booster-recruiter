# Booster Recruiter 0.3.2: что нового

## Для рекрутера
- **Узкое окно.** Кнопки кампании переносятся под название, поисковый запрос больше не сжимается в узкую колонку.
- **Аккаунт отправителя.** Подсказка на странице кампании называет аккаунт и что с ним («требуется вход»), а не просит подключить уже подключённый.
- **Возврат из архива** упоминает план на паузе, только если он есть.
- **Требует внимания.** Запрос входа не повторяет имя аккаунта дважды; подтверждение архива или удаления не появляется на другом экране.
- У аккаунта без активной сессии больше нет двойной разделительной линии.
- Кампания, ожидающая следующей проверки, помечена «По расписанию», а не «Ждёт рабочих часов».
- Подтверждённое приглашение сразу отмечает контакт как «Приглашение ожидает принятия», а не «Нет контакта».

## Для разработки
- Браузерный движок в коде называется по Patchright: `patchright_session`, `BrowserTimeoutError`. Остаётся только переменная `PLAYWRIGHT_BROWSERS_PATH`: её читает сам Patchright.
- Признак «нужен вход» в записях внимания берётся из статуса аккаунта, а не из текста подсказки.
