# Booster Recruiter 0.4.0: что нового

## Для рекрутера
- **Английский интерфейс.** Английский — язык по умолчанию; русский выбирается в «Настройках» → «Язык интерфейса». Переведены все экраны, диалоги, подсказки, ошибки и статусы, меню приложения и значка, системные диалоги, уведомления и выгрузка в Excel/CSV.
- **Рабочие часы в формате AM/PM** во всех настройках и сводках плана (например, 8:00 AM–8:00 PM).
- **Проверка соответствия запросу.** Найденный профиль сохраняется, только если в его тексте выполняется поисковый запрос (AND/OR/NOT, фразы в кавычках, скобки; формы слов учитываются). Если на главной странице совпадения нет, перед отказом читаются опыт и навыки. Отклонённые профили не открываются повторно.
- **Понятный конец поиска.** Если LinkedIn выдал меньше профилей, чем нужно, статус говорит об этом и предлагает упростить запрос.

## Для разработки
- `src/i18n.js`: `t()` для текстов интерфейса, `tr()` для сообщений сервиса; каталоги по областям в `src/i18n/en/`. `scripts/i18n_check.mjs` проверяет полноту перевода.
- Язык хранится в `desktop-preferences.json` (`language`), передаётся окну при каждой загрузке; IPC `set-language`.
- `backend/booster_recruiter/search_match.py` и таблица `search_rejects`.
- UI-регрессии запускаются на русском; новый `scripts/ui_english_tour.cjs` проверяет английскую версию и переключение языка.
