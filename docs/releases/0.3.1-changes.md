# Booster Recruiter 0.3.1: что нового

Исправления после проверки 0.3.0 на реальных аккаунтах.

## Для рекрутера
- **Требует внимания.** Если аккаунт отправителя вышел из LinkedIn, «Уточнить статус» не запускается вхолостую: запись объясняет, что нужен вход, а кнопка открывает этот аккаунт. Запросы входа стоят первыми и показывают, когда появились.
- **Кандидаты.** Если человека нельзя выбрать, в строке видна причина: например, он уже в другой действующей кампании. Сводка считает «Обычный текст»; «Без группы» появляется, только если такие профили есть.
- **Excel и CSV.** Группы, рамки, статусы и каналы записаны по-русски, время — местное, в виде «дд.мм.гггг чч:мм».
- **Архив и удаление.** После переноса в архив или удаления кампании появляется подтверждение.
- **Резервные копии.** У каждой копии указан тип (ежедневная, созданная вручную, перед восстановлением) и размер в МБ.
- **Перед запуском.** Окно проверки текстов аккуратнее: часовой пояс назван городом, разделы разнесены.
- **История контактов.** Колонки всех планов выровнены.
- **Новая кампания.** Поле поиска больше не прилегает к числу профилей, переключатель запроса выглядит как ссылка.

## Для разработки
- Экспорт вынесен из `store.py` в отдельный модуль `export.py`.
- Названия часовых поясов собраны в `labels.js`.
- У аккаунтов появилось поле `status_changed`; старые записи получают дату создания.
