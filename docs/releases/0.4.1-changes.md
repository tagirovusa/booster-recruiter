# Booster Recruiter 0.4.1: исправления

## Для рекрутера
- **Пауза отправителя не трогает архив.** Ограничение LinkedIn или запрос входа у отправителя больше не переводят в «Пауза» архивные кампании и кампании, которые сейчас не работают.
- **Наблюдение за ответами** считается от первого обращения к человеку, а не от создания плана. Срок наблюдения должен быть больше срока ожидания принятия приглашения — иначе настройки не сохранятся.
- **Статус кампании совпадает с планом.** Если у кампании есть активный план, после поиска, проверки контактов или ошибки она остаётся «По расписанию», а не «Готово» или «Пауза». «Приостановить все кампании» не меняет статус кампаний без работы. После перезапуска приложения прерванная работа без активного плана помечается как пауза.
- **Подтверждение только в окне приложения.** Агент (MCP) больше не может возобновить план, запустить проверку «сейчас» или отметить результат неясной отправки — это делается только в окне Booster Recruiter.
- **Кампания из шаблона** с устаревшими настройками больше не оставляет пустую кампанию: ошибка показывается до создания.
- **Долгие действия** (открытие профиля, удаление аккаунта, восстановление копии) больше не сообщают «Операция заняла слишком много времени», пока ещё выполняются. Если служба приложения остановится при запуске окна, появится сообщение «Сервис остановлен».
- **Конец поиска.** Если LinkedIn больше ничего не находит по запросу, кампания показывает «Поиск завершён — LinkedIn больше ничего не находит» и кнопку «Изменить поиск» вместо «Продолжить поиск».
- **«Требует внимания»:** при ошибке обновления видна её причина в «Технических подробностях». Статус человека теперь называется «Нужна проверка» — отдельно от раздела «Требует внимания» (и в выгрузке).
- **Вкладка «Отправка»** называется одинаково везде; строка следующей проверки показывает город часового пояса (например, «Нью-Йорк») вместо `America/New_York`.
- **Английский режим:** комментарии и причины в выгрузке Excel/CSV и ошибки «Приостановить все кампании» в меню значка теперь на английском.

## Для разработки
- `api.py`: `outreach.resume`, `outreach.check_now`, `outreach.resolve`, `delivery.resolve` в `DESKTOP_ONLY`; MCP-инструмент `resume_approved_outreach` удалён (15 инструментов).
- `Store.settle()` / `has_active_plan()`, `Runtime._has_running_task()`; восстановление после перезапуска переводит `automating` в `paused`.
- Колонка `campaigns.search_exhausted_keywords` (добавляется при запуске и при восстановлении старой копии).
- `desktop/command_timeouts.cjs` — время ожидания по операциям; обработчик выхода службы подключается сразу после её готовности.
- `scripts/export_i18n_catalog.mjs` пишет общий английский каталог в `backend/booster_recruiter/i18n_en.json` и `desktop/i18n_en.json` (`--check` в `npm run test:ui`); `export_i18n.translate()` и `tr()` в `desktop/i18n.cjs` повторяют `tr()` окна.
- Код Python отформатирован `ruff format`.
