# Booster Recruiter · 0.2.5

Локальное приложение Business Booster для подбора кандидатов в LinkedIn. Интерфейс на русском. Основные сценарии работают без облачного ИИ и подписки на ИИ-сервис. Надписи Open to Work/Hiring распознаёт локальная OCR-модель; это машинное распознавание текста, не LLM.

**Статус: сборка-кандидат для контролируемой приёмки. Windows-приёмка версии 0.2.5 ещё не подтверждена.** Автоматические и офлайн-проверки не заменяют проверку установленного приложения и входа на целевой ОС. См. [матрицу приёмки Windows](docs/WINDOWS-ACCEPTANCE.md) и [отчёт о предыдущей проверенной версии](docs/RELEASE-STATUS.md).

## Возможности

- Отдельная сессия и подтверждённая личность для каждого LinkedIn-отправителя. Кампания закрепляется за выбранным аккаунтом.
- Поиск по ключевым словам LinkedIn или по одной явно вставленной ссылке на профиль. Из результатов поиска исключаются ссылки на взаимные контакты, чтобы не принимать их за найденных кандидатов.
- Распознавание текущего действия Connect проверяет связь именно с открытым профилем, включая имена/ссылки с Unicode. Если LinkedIn не даёт достаточно подтверждений, приложение останавливает действие, а не угадывает.
- Сбор публичных URL, имён, заголовков, доступных сведений и фотографий профилей. Результаты сохраняются по мере обработки.
- Локальное распознавание рамок Open to Work и Hiring. Все остальные профили получают нейтральную группу, если рекрутер вручную не выбрал другое. `Не определена` не доказывает отсутствие рамки или занятость.
- Проверка получателей и текстов до запуска. Поддерживаются приглашения, обычные сообщения и InMail, если соответствующий канал доступен и отдельно утверждён.
- Дневные лимиты приложения общие для кампаний и браузерных слотов одной подтверждённой личности отправителя; сутки считаются по UTC. Это локальные пределы приложения, не официальные лимиты LinkedIn и не учёт действий вне него.
- Пауза, история, запрет дальнейшего контакта, проверка ответов и экспорт: список кампании в Excel, результаты сообщений в CSV.
- Для остановленной кампании можно повторно проверить контакты без отправки, если для выбранного получателя ещё не было попыток и результат проверки был неопределённым. Проверка не снимает паузу и не возобновляет отправку.
- Если LinkedIn сообщает об ограничении личности, связанные кампании ставятся на паузу. Не пытайтесь снять ограничение автоматическими повторными входами.
- Необязательный MCP-адаптер управляет теми же кампаниями. Новую отправку подтверждают в интерфейсе приложения.

Не реализованы: email-рассылка, отдельный кабинет Sales Navigator, автоматические follow-up после молчания, синхронизация команды, автообновление и автоматическое определение занятости. Premium не снимает ограничений доступных каналов. Некоторые поля профиля могут отсутствовать; сохраняйте исходный текст для ручной проверки.

## Разработка и сборка

Требуются Node.js 24 и uv. Секреты и действующие сессии в комплект не включены.

```sh
uv sync --frozen --python 3.13.16 --group dev
npm ci
uv run pytest -q
npm run build
uv run python scripts/collect_licenses.py
uv run python scripts/build_runtime.py
uv run python scripts/runtime_smoke.py
npm run test:ui
npm run desktop
```

Сборку Windows выполняйте на Windows 10/11 x64 через `BUILD-WINDOWS.cmd`. Скрипт устанавливает закреплённые инструменты в папку проекта, проверяет архивы по SHA-256, запускает офлайн-проверки и создаёт NSIS-установщик. Имя установщика берётся из версии `package.json`, например `Booster-Recruiter-0.2.5-Windows-x64-Setup.exe`. Перед передачей проверьте точное имя и SHA-256: в `release` могут оставаться артефакты предыдущих сборок.

Приватная передача установщика возможна. Установщики Windows не подписаны сертификатом издателя; macOS-пакеты этой линии собираются с ad hoc подписью без Developer ID/notarization. ОС может показать предупреждение неизвестного издателя. Устанавливайте только файл, полученный из согласованного источника, и не отключайте системную защиту.

Пакет macOS этой линии предназначен для Apple Silicon. Сборка и установщик версии 0.2.5 не означают, что приёмка на Windows пройдена.

Лицензии сторонних компонентов находятся в `licenses/` и каталогах встроенных браузеров. Встроенный браузерный адаптер находится в `vendor/booster-linkedin` и собирается вместе с приложением.
