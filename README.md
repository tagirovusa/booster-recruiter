# Booster Recruiter · 0.2.2

Локальное приложение для подбора кандидатов в LinkedIn. Интерфейс на русском языке, оформление Business Booster. Основные сценарии работают без облачного ИИ и без подписки на ИИ-сервис. Для распознавания надписей на рамке используется локальная OCR-модель; это машинное распознавание текста, а не LLM.

**Статус: кандидат для испытаний, не подтверждённый production-релиз.** macOS и Windows используют общий код. Сборка и проверка Windows выполняются на Windows. Точная матрица проверок и оставшиеся ограничения — в [RELEASE-STATUS.md](docs/RELEASE-STATUS.md).

## Реализованные сценарии

- Отдельная браузерная сессия каждого LinkedIn-аккаунта; вход непосредственно на странице LinkedIn.
- Кампания с фиксированным отправителем, ключевыми словами и объёмом поиска.
- Сбор публичных URL, имён, заголовков, доступных исходных сведений и фото профиля; сохранение после каждого профиля.
- Локальное распознавание Open to Work / Hiring. Профили без распознанного Open to Work получают нейтральный шаблон. Отсутствие распознанной надписи не доказывает ни отсутствие рамки, ни трудоустройство.
- Два шаблона с переменными; ручная проверка группы; предварительный просмотр точного отправителя, получателей и каждого текста.
- Утверждённая кампания: приглашение, ожидание принятия, обычное сообщение, платный InMail с темой и бюджетом. Экономный и быстрый режимы. Неизвестный результат не повторяется.
- Расписание, проверка ответов, работа в фоне через значок приложения, сохранение очереди после перезапуска. Приглашение, принятие и отправка проверены на согласованном профиле на Mac.
- LinkedIn Recruiter: контракт, кредиты, собственные тексты, нативная подпись в предпросмотре, бесплатный или платный InMail с проверкой истории.
- Пауза, продолжение утверждённой очереди, история, запрет дальнейшего контакта, экспорт XLSX/CSV.
- Необязательный MCP-адаптер к тому же открытому приложению. Новую отправку подтверждает пользователь в интерфейсе.

Не реализованы: email-рассылка, отдельный кабинет Sales Navigator, автоматические follow-up после молчания, синхронизация команды, автообновление, автоматическое определение занятости человека. Premium не снимает ограничения доступных каналов сообщений. Отдельные поля профиля могут остаться пустыми; исходный текст сохраняется для проверки.

## Разработка

Требуются Node.js 24 и uv. Секреты и действующие сессии в проект не включены.

```sh
uv sync --frozen --python 3.13.16 --group dev
npm ci
uv run pytest -q
npm run build
uv run python scripts/collect_licenses.py
uv run python scripts/build_runtime.py
uv run python scripts/runtime_smoke.py
npm run test:ui
npm run desktop
```

Сборка на Mac: `CSC_IDENTITY_AUTO_DISCOVERY=false npm run package:mac`.
На Windows: запустите `BUILD-WINDOWS.cmd`. Скрипт загружает фиксированные версии инструментов, проверяет контрольные суммы архивов, запускает тесты и создаёт NSIS-установщик. Рекрутеру инструменты разработки не нужны.

Встроенный браузерный адаптер находится в `vendor/booster-linkedin` и собирается вместе с приложением. Лицензии сторонних компонентов находятся в `licenses/` и каталогах встроенных браузеров.
